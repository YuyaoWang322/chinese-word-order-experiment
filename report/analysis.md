# 词序的奥秘——实验分析

# 空最终回答排除规则

用户要求剔除没有响应的记录。本次仅排除空白/纯空白最终回答，已从正式样本剔除11条，并从相同模型、相同任务的未入选非空真实回答中按固定种子补入11条，仍为每模型30条（恢复/问答各15条）。其余原入选记录和已保存人工评分不变。错误但非空的回答未因成绩被排除。原空回答、原名单及替换名单完整保留。统计现在是“有最终回答条件下”的表现，不能代表全部调用成功率，也不能与排除前的总准确率直接比较。空回答被排除可能造成选择偏差。

## 1. 实验设计
6 段中文（3 类×2 段），4 个条件（含原文对照），2 项任务，每组合独立重复 3 次。扰动固定 seed=20260927，固定分词；各重复共用同一扰动文本和 prompt。DeepSeek API 采用独立请求，无历史对话；调用顺序固定随机化。GPT 网页版通过独立临时对话采集，网页采样参数不可控，采集方式的差异须纳入解释。新增CodeBuddy CLI模型采用独立进程、禁用工具、空目录和固定系统提示词，逐次核对响应模型；WorkBuddy界面预试验已暂停并保留。重复是同一文本的技术重复，不是独立文本样本。

## 8. AI 是否真正理解语言
实际任务回答与评分见表。有限文本上的正确回答只能支持相应任务表现；无法单独区分理解、模式匹配、记忆或猜测，更不能据此证明或否定“真正理解”。

## 9. 稳定性与局限
详见 results/summary/stability.csv：三次评分齐全才计算样本标准差、极差和全一致率。三次输出完全相同不等于语义表现稳定。每类只有两篇，禁止把重复调用当成独立文本扩大样本量。重度保留标点位置、打乱汉字；QA 问题本身提供语义线索；单一固定扰动版本不能代表所有乱码。自动 QA 为严格格式准确率，人工复核需留名和说明。
